# Smart Ration & Expense Manager

A simple browser-based app for tracking household ration, grocery, and other expenses.

## Features

- Set a monthly budget in Indian rupees (₹)
- Add expenses by category
- Filter the list by category
- See total spending and a budget warning
- Delete individual entries or clear all expenses
- Export entries to CSV
- Save expenses and budget in the browser using `localStorage`
- Responsive layout for mobile and desktop

## Run locally

1. Download and extract this ZIP file.
2. Open `index.html` in a modern web browser.

No installation or build step is required.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `app.js`, and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and the `/ (root)` folder, then save.
6. After GitHub Pages finishes deploying, open the website URL shown in the Pages settings.

## Important note

Expenses and the budget are saved in the browser on the device where you use the app. They are not automatically synced to GitHub or other devices. Clearing browser data may remove the saved information, so export CSV backups when needed.
